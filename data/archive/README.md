# Archived traces (not demos)

These recordings were made **before** traces were pinned to a block height (Step 4). They read only each wallet's newest 1,000 transactions, so they cannot be reproduced. They are kept only as a before-and-after exhibit for the deck.

Nothing here is listed by `/demos` or served by replay, which only read `data/cache/`.

- `0x62425cd6...pre-pinning.json`: headlined **Coinbase, 19.01 ETH, 2 hops**. Once history is read back from a pinned block, the same address headlines **Binance**, including at the block where this recording was made. The Coinbase answer was produced by the 1,000-row window.
- `0x098b716b...pre-pinning.json`: Ronin. Same headline as today (Huobi 2,500 ETH); it predates the calibrated fan-in thresholds.
